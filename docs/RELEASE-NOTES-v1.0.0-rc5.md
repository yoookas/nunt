# nunt v1.0.0-rc5

第五个候选版本，只有前端修正：登录页布局、多选控件的浮层与可点击行的键盘可达性。
没有后端、配置或数据格式变化。

## 修复与调整

- **登录页布局**：原来颜色模式按钮用绝对定位放在页面角落，宽屏时离卡片太远、矮窗口下可能压到表单。
  现在是纵向两段：顶部工具条（右侧放颜色开关）+ 卡片在剩余空间居中，控件回到正常文档流，
  与后台顶栏的位置一致。
- **多选（省份筛选）换成官方浮层**：原先手写的绝对定位下拉在弹窗的滚动区域里会被裁剪。
  现在用 `Dropdown` + 多选 `Menu`，浮层走 portal 并有碰撞检测，勾选多项时菜单保持打开，
  键盘可操作；触发器的标签外观保持不变。
- **可点击行的键盘可达性**：监听器表格里用来切换选中监听器的单元格原来是裸 `div`，
  现在有 `role="button"`、进入 Tab 顺序、Enter / 空格触发和可见焦点环；
  监听器卡片与「全部监听器」行增加 `aria-pressed`。

## 升级

换镜像即可，配置与数据完全兼容：
- 已登录的会话仍在内存里，重启后需要重新登录一次；
- 前端产物已随镜像重新构建，浏览器强刷一次即可拿到新界面。

## 仍未验证（同前）

- 真实 Let's Encrypt 签发与自动续期、真实 DNS 账号联调；
- 真机 `docker compose` 长期运行；
- 浏览器逐页 E2E、24 小时长跑与压测；
- 本次的多选浮层没有自动化覆盖（jsdom 冒烟不打开表单弹窗），请在 Web 路由 / 端口转发的省份选择里确认一次。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc5-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc5 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
