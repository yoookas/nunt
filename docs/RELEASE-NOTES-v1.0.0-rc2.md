# nunt v1.0.0-rc2

第二个候选版本：只修 rc1 暴露的问题，没有新增功能。

## rc1 → rc2

### 修复

- **表单弹窗位置不对**：所有表单之前用的是侧边抽屉组件（`Drawer`），在宽屏上贴在左边缘、看起来像浮窗跑偏了。
  现在改用居中的对话框（`Modal`），内容超高时只在对话框内部滚动。
- **腾讯云 DNS（DNSPod）签发证书失败**：TC3 签名把没有参与规范化的 `X-TC-Action` 列进了 `SignedHeaders`，
  每一次调用都被拒为 `AuthFailure.SignatureFailure`。现在与官方 SDK 一致，只签 `content-type;host`；
  dns-01 的 TXT 记录创建与清理恢复正常。
- **空状态里的多余筛选**：一个监听器都没有时，不再显示「全部监听器 0」那一行。

### 改进

- **统计不再静止**：概览 5 秒、端口转发 5 秒、动态域名 10 秒自动刷新；标签页隐藏时暂停，切回立即更新。
  轮询失败时页头出现「刷新失败，点击重试」，恢复后自动消失——不再需要手动点刷新。
- **统计卡片更紧凑**：三行的大卡片改成单行瓦片，宽屏上端口转发的 6 个指标占一排。
- **筛选并入卡片标题行**：Web 路由、DDNS 规则、转发规则的搜索/筛选与计数移到标题行，省掉整行高度。
- 概览的 24 小时请求趋势每 5 分钟刷新一次（按小时聚合，没必要更频繁）。

### 发布流水线

- OCI 归档现在也会生成并收集校验和，`SHA256SUMS` 覆盖全部四个归档（rc1 只有三个单架构归档）。

### 工具链

- Go 1.26.11：修复 `GO-2026-6859`（HTTP/1 服务端因 `MaxBytesReader` 头部竞争崩溃，可达路径在管理面与代理上）。
  这一项 rc1 已包含，这里一并说明。

## 仍未验证（与 rc1 相同）

- 真实的 Let's Encrypt 签发与自动续期；
- DNS 提供商真实账号联调（腾讯云本次修复有签名级测试与假 API 验签，但没有用真实账号调过）；
- 真机 `docker compose` 的长期运行（CI 里跑的是启动 + 契约检查）；
- 浏览器逐页 E2E（只有 jsdom 挂载冒烟）；
- 24 小时长跑与压测。

## 镜像

```sh
docker load < nunt-v1.0.0-rc2-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc2 docker compose up -d
```

`amd64` / `arm64` / `armv7` 是单架构归档，`-oci.tar.gz` 是三平台合一的 OCI 布局（`docker load` 读不了，需要 `ctr` 或 podman）。
四个归档的校验和都在 `SHA256SUMS` 里。

## 从 rc1 升级

换镜像即可：本版本没有配置字段变化，数据目录（`config.json`、`secret.key`、证书、日志）保持兼容。
回滚同理，但仍建议回滚时一并回滚数据目录。
