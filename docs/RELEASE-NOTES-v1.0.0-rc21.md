# nunt v1.0.0-rc21

第二十一个候选版本：日志页只保留一个滚动区，页面本身不再滚动，手机上的工具条
压缩成单行。

## 日志页：整页填满，只有列表滚动

- 运行日志与访问日志都改为填满可视区域，页面根节点不再出现滚动条；
- 表头/列表头固定，只有表格或日志列表内部滚动；
- 删除了内容区重复的「日志」大标题（顶部栏已经有），保留一个屏幕阅读器可见的隐藏标题；
- 访问日志的 4 个统计卡片压缩成一行文字，存储状态收进底部一行；
- 运行日志的工具条与列表也改为同样的满高布局。

## 手机端

- 访问日志的筛选收进「筛选」弹层，不再把表格挤成 0 高度；
- 运行日志的级别与关键字并排一行；
- 所有操作按钮保持单行、可横向滑动，不再换成两行：
  - 访问日志：筛选 / 刷新 / 导出 / 清空 / 自动刷新；
  - 运行日志：暂停 / 清屏 / 计数 / 自动滚动；
- 滚动条只在日志列表内部出现。

## 验证

- 1500×950、1280×720、1024×768、iPhone 13、iPhone SE 下页面 `scrollHeight == clientHeight`；
- 访问日志表格在这些视口下分别保留 642 / 326 / 356 / 296 / 140 px 高度；
- 手机访问日志操作条内容 392px、可视 356px，可横向滑动；
- 前端构建与 11 条路由冒烟通过。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc21-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc21 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
