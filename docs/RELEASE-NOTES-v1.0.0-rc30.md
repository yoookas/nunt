# nunt v1.0.0-rc30

第三十个候选版本：日志页的跟随与组件列修好，Web 服务和日志两页的页签改为贴着顶栏。

**没有配置变更**，升级后不需要重新配置任何规则。

## 日志页

- **「组件」列终于有值了**。日志页读的是 `attrs.component`，而后端只有 API 日志用了这个属性名，
  各模块打的是 `attrs.module`，所以 web / forward / ddns / waf 的行一直显示 `-`。
  现在模块日志统一打 `component`，启动日志打 `component=app`；新增测试钉住这个属性；
- **Web 访问 / 端口转发两个 Tab 也会自动跟随**。原来「自动刷新」默认关闭、翻动列表也不会
  改变它；现在和运行日志一致：
  - 进入页面（在顶部）时默认开启，每 10 秒刷新；
  - 向上翻看历史自动暂停，不会把正在看的位置打断；
  - 滑回顶部自动恢复，并且**立即**拉一次最新，不用等下一个 10 秒；
- 运行日志的绿色「实时连接中 / 实时更新」徽标删除了：健康的流不占位，只有
  正在连接、正在重连、连接已断开这三种状态才显示徽标。

## 布局

- Web 服务和日志两页的页签改为**贴着顶栏**：这两页的 Tab 条本身就是页面级导航，
  之前保留了内容区的 24px 上内边距，视觉上是一段空白（其他页面在同样位置是带边框的卡片，
  所以不显）。现在抵消上内边距并在测量高度里补回，内容整体上移 24px（手机 12px），
  底部高度不变。

## 验证

- `gofmt` 干净；`go vet ./...`、`go build ./...` 通过；
- `go test ./... -count=1`：23 个包、412 个测试全部通过（新增
  `TestDepsLoggerTagsComponent`）；
- `npm run build`、`npm run smoke`（10 条路由）通过；
- Playwright 截图核对：Web 服务页、日志页（含 SSE 真实连接状态）、跟随开关状态机
  （初始开 → 滚动暂停 → 回顶恢复）实测通过。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc30-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc30 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
