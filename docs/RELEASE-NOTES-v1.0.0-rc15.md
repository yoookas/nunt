# nunt v1.0.0-rc15

第十五个候选版本：IP 访问过滤上移到监听器，路由可继承或自定义；国家、省份、城市
合并为一个输入框。

## 监听器级过滤

- `web.listeners[]` 新增 `access`：访问策略、IP/CIDR、地区、UA 策略与列表；
- 监听器表单底部新增「访问过滤（监听器默认）」，作用于本监听器下所有
  「继承监听器」的路由。

## 路由继承或自定义

- 路由的访问策略新增 **继承监听器**（`access.mode: "inherit"`）：
  - 继承：使用所属监听器的规则；
  - 关闭 / 白名单 / 黑名单：路由自定义，**覆盖**监听器规则（不叠加）；
- 选择继承时，路由自身的 IP/地区/UA 列表会被清空，不保留无效字段。

## 地区列表扁平化

- 不再分开填写国家、省份；同一个输入框接受**国家、省份、城市**，同一列表取并集；
- 匹配 ip2region 的 `country / province / city` 三个字段：
  - 省份两种写法都接受：`浙江`、`浙江省`（自治区、特别行政区等后缀同样归一）；
  - 城市忽略行政后缀：`杭州`、`杭州市`（`地区`、`自治州`、`盟` 同理）；
  - 国家按地址库中的值比较，忽略大小写；
- 与 IP/CIDR 列表仍是并集，命中任意一项即匹配。

## 兼容与清理

- 旧的 `access.countries` / `access.provinces` 仍会被读取一次，合并进 `access.geo`
  后清空，旧配置无需手工迁移；
- 删除 `/api/v1/system/ip2region/provinces` 接口、前端省份选择器与 `MultiSelectInput`；
- 地址库加载不再做全量省份扫描（v4 库启动/上传更快）。

## 验证

- 新增单测：三级名称匹配（国家/省份/城市、简写与全称）、监听器规则继承、
  自定义覆盖、旧字段迁移、转发规则拒绝 inherit；
- 实机验证：监听器 allow `杭州` 时继承路由放行、改成 `上海` 后拒绝，自定义路由不受影响；
- 全量 `go vet` / `go test ./...`、前端构建与 11 条路由冒烟通过。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc15-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc15 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
