# nunt v1.0.0-rc22

第二十二个候选版本：访问日志完全交给无限滚动，去掉多余的「加载更多」按钮，
并修正滚动时表头被数据行穿透的问题。

## 无限滚动

- 删除访问日志底部的「加载更多」按钮；
- 滚动到接近底部会自动请求下一页并追加；
- 底部只保留数量与存储摘要（`已显示 N 条 · SQLite 保留天数 / 上限 · 占用`），
  加载下一页时显示「正在加载…」；
- 筛选、刷新、导出、清空、自动刷新不受影响。

## 表头

- 之前横向/纵向滚动后，数据行会画在表头文字上（`thead` 的层级在表格布局里不生效）；
- 现在 sticky 应用到表头单元格，表头始终在上方，首行数据在其下方；
- 只影响启用虚拟滚动的表格（访问日志）。

## 验证

- 首屏 100 条，连续滚到底自动加载到 230 条；
- 滚动到中段时表头完整可见，没有行穿透；
- 前端构建与 11 条路由冒烟通过。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc22-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc22 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
