# nunt v1.0.0-rc23

第二十三个候选版本：管理界面整体重做为基于 Ant Design 5 的「指挥中心」，模块页改为
主从工作区（列表 + 详情），手机端列表进入整页详情。**后端、数据库和 REST API 没有变化。**

## 布局与导航

- 去掉固定左侧栏，改为顶部横向导航；移动端用汉堡按钮打开抽屉导航，不使用底部栏；
- 概览改为模块入口：状态条 + 模块卡片 + 最近 24 小时请求 + 最近日志；
- 增加 ⌘K / Ctrl+K 命令面板，可跳转任意模块；
- 主题支持浅色 / 深色 / 跟随系统，默认跟随系统；
- 顶栏去掉 nunt 图标、名称和头像：单管理员应用没有需要展示的用户身份；修改密码和退出登录
  收进最右侧的 ⋯ 菜单。

## 模块页

- Web 服务：监听器 / 路由分段主从工作区，选中即编辑，新建为草稿，监听器与路由都支持拖动排序；
- 端口转发、动态域名：列表 + 详情内联表单；启停、端口占用、掩码凭据等原有行为保留；
- 证书：证书 / 任务 / 续期状态三种列表 + 详情，任务内联编辑，上传与账户改为抽屉；
- WAF：安全控制台（状态条 + 引擎配置 + 规则策略 + 拦截事件 + 在线测试）；
- 日志：全高控制台，页面不滚动，只有日志区滚动；访问详情桌面右侧抽屉、手机全屏；
- 设置：左侧分组导航 + 右侧内容，手机分组列表 → 详情；
- IP 地址库：双库卡片 + 拖拽上传 + 查询面板。

## 兼容性

- 前端技术栈为 React 19 + Ant Design 5 + Vite 8；构建产物仍提交在 `internal/webui/assets/`；
- 无数据库迁移、无配置格式变化、无 API 变更，替换镜像即可；
- TOTP 仍以 secret + `otpauth` URI 展示，未内置二维码图片。

## 验证

- 全量 `go vet` / `go test ./...` 通过；
- `npm run build`、`npm run smoke`（10 条路由）通过，构建产物与源码一致；
- 1440 / 768 / 390 三种宽度遍历全部页面，无横向溢出和运行时错误；
- 监听器/路由拖动排序、内联新建/编辑、移动端列表→详情流程实测通过。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc23-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc23 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
