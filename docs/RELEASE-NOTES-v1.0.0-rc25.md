# nunt v1.0.0-rc25

第二十五个候选版本：访问控制改成有序规则，WAF 可以在监听器上设默认，概览页和导航重做。
**有配置不兼容：旧的访问规则和 WAF 开关不会迁移，升级后需要重新配置。**

## 访问控制：有序规则

`mode=allow|deny` 的单列表换成了**两条独立的有序列表**，每条末尾有一行固定的「其余流量」：

- 地址列表：IP 段（CIDR）与 ip2region 国家/省份/城市混排，**从上到下匹配，第一条命中的生效**；
- 客户端列表：User-Agent 片段，同样有序；
- 两条列表是 AND 关系：地址放行后，UA 还要放行；
- 地区库查询失败仍然 fail-closed；IP 命中时完全不查地址库。

由此得到旧模型做不到的能力，例如「允许 `10.0.0.0/8`，但封掉其中的 `10.0.0.66`」，以及反过来的「封掉整段，单独放行某个地址」。

**不兼容**：旧字段（`mode=allow|deny`、`ips`、`geo`、`uaMode`、`uas`）不再被识别，升级后这些规则等同于「关闭过滤」。原本的白名单会变成放行所有人，请升级后立刻重新配置。

## WAF：监听器设默认，路由继承

- 监听器新增「启用 WAF」开关，作为该监听器下路由的默认值；
- 路由的 WAF 开关改成三态：`继承监听器 / 启用 / 关闭`，继承项会直接显示解析结果；
- 列表行标签区分 `WAF`（本路由开启）与 `WAF（继承）`；
- 全局 `waf.enable=false` 仍然是一票否决。

**不兼容**：旧的 `waf: true` 不再读取，需要重新勾选。

## 概览页

- 标题、版本、运行时间、健康状态合并成一张卡片，去掉刷新按钮（页面每 10 秒静默轮询）；
- 「系统资源」一张卡：CPU 负载、内存、Go 堆内存三条进度条；
- 「磁盘」一张卡：按挂载点显示，每个挂载点一条进度条；
- Web 服务、端口转发、动态域名、证书合并成一条「服务」窄带，去掉跳转；
- 删除 WAF、今日请求、日志、IP 地址库、设置这几张卡片；
- 请求图拆成「Web 服务请求」和「端口转发请求」，各自 24 小时、按小时聚合。

## 界面

- 顶栏去掉图标，只保留文字；
- Web 服务页：监听器/路由改成 Tab；整页不再滚动，列表与详情各自滚动，筛选项和保存栏固定在各自面板内；
- 刷新按钮删除，改为 10 秒轮询（切到后台时暂停，失败只把状态点变红）；
- 访问规则编辑器：每行可选允许/拒绝、IP 段/地区、值，支持上下移动，末尾「其余」行不可移动或删除。

## 工程

- 修复转发规则指纹：修改访问规则或**调整条目顺序**都会重建代理（此前不会）；
- 测试文件按主题拆分（web / waf / forward），测试数量不变（410 → 410）；
- 移除仓库里 4.8 MB 的误提交测试二进制 `logstore.test`，`.gitignore` 增加 `*.test`；
- 文档新增 `docs/ACCESS-RULES.md`（有序规则规格），README 补充「后台放在 TLS 代理后面」的配置配方。

## 验证

- `go test ./... -count=1`：22 个包全部通过；

- 概览页与 Web 服务页用 Playwright 在 1440×1000 / 390×844 下截图核对，页面滚动量为 0。

