# nunt v1.0.0-rc29

第二十九个候选版本：修掉概览页图表、WAF 统计、登录页深色模式和密码策略上的六处问题。

**没有配置变更**，升级后不需要重新配置任何规则。

## 概览页

- **三条线回到同一根 Y 轴**。上一版把拦截线放在右轴上，同一时刻「总请求 119 / 访问规则拦截 119」
  会被画在图表的两端，读数与图形对不上；现在同量即同高，整小时被拦的尖峰与总请求线重合；
- 线条不再在两端渐隐（bklit 默认 `fadeEdges`），首个和最后一个小时桶都画到满强度；
- 悬停面板从「白底 + 深色描边」换成 antd 的填充色与边框色：浅色下是浅灰、深色下是抬高的深灰，
  阴影也收轻，和卡片融为一体。

## WAF 页面

- 状态卡片补上「通过」。此前只有 检查 / 拦截 / 检测 / 错误，18,432 次检查 + 57 次拦截 + 0 + 0
  加不回 18,432，剩下的 18,375 次通过根本没显示；
- 「检测」改名「仅记录」，并给每个指标加了说明；拦截模式下它恒为 0 是正常的，旧名字看起来像坏了；
- 事件面板的「共 N 条」按当前筛选统计：选「拦截」时不再显示未筛选的缓冲区总量；
  后端 `/api/v1/waf/logs` 现在同时返回 `total`（整个环形缓冲）与 `matched`（符合 `action` 的数量），
  后者遍历全部 500 条缓冲计算，不受 `limit` 截断。

## 登录与密码

- **登录页深色模式修好了**。页面此前用 `var(--ant-color-bg-layout, #f5f5f5)`，而本项目没有开启
  antd 的 `cssVar`，这个变量永远不存在，永远回落到浅灰——深色模式下是一片浅色背景托着深色卡片。
  现在直接用 `token.colorBgLayout`，与主布局同源；
- **密码策略统一到前端**：至少 6 位，且必须同时包含字母、数字、符号。缺哪类就提示哪类
  （例如「还需要包含符号」），不再是笼统的长度报错；
- 后端不再校验强度（此前是 8 位，与前端要求的 12 位互相打架），只保留「不能为空」——
  空密码等于把账号变成免密登录。

## 验证

- `gofmt` 干净；`go vet ./...`、`go build ./...` 通过；
- `go test ./... -count=1`：23 个包、411 个测试全部通过（`TestAPILogs` 补充了
  `matched` / `total` 的筛选断言）；
- `npm run build`、`npm run smoke`（10 条路由）通过；
- Playwright 截图核对：概览浅色 / 深色 / 悬停、登录浅色 / 深色、密码规则报错、WAF 页面。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc29-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc29 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
