# nunt v1.0.0-rc6

第六个候选版本：腾讯云 DNS 写入参数修正、首次登录改密的独立屏与服务端强制，
以及密码页、IP 过滤的细节修正。没有配置格式变化。

## 修复

- **腾讯云 DNS 仍无法创建 TXT 记录**：`CreateRecord` / `ModifyRecord` 的参数名是
  `SubDomain`（大写 D），而 `DescribeRecordList` 是 `Subdomain`。写入时用了小写，被 API 以
  `UnknownParameter The parameter 'Subdomain' is not recognized` 拒绝。现已按文档区分，
  测试里的假 API 也会像真 API 一样拒绝未知参数，防止再写错字段名。
- **改密后当前会话也被删除**：修改密码原本会踢掉**包括当前会话在内**的所有会话，首次登录
  改完密码立刻被弹回登录页。现在只保留发起改密的那个会话，其它会话照旧失效。
- **省份下拉可能给出无法保存的选项**：候选来自数据库扫描结果，现在只保留能通过校验的省份。

## 首次登录改密：独立界面 + 服务端强制

- `/password` 是控制台外壳之外的独立屏：没有侧栏和导航，只有一张卡片和「退出登录」；
- 服务端同时强制：未改密的会话**只能访问** `session`、`password`、`logout` 三个接口，
  其它请求一律 `403 password_change_required`——不再是前端跳转的「装饰」；
- 主动改密仍在控制台内（`/account/password`），保留页面标题和返回按钮；
- 相关边角：配置导入若替换了管理员（ID 或密码哈希变化），会清空全部会话；
  登录后 flag 才出现时，前端收到 403 会立刻切到改密屏。

## 小改进

- 强制改密页居中、去掉重复标题，首次登录的说明文案单独区分；
- 登录页改为「顶部工具条 + 居中卡片」（rc5 已包含），本次沿用；
- IP 过滤补充多国家/多省份用例：命中列表里的第二项也生效，allow / deny 都覆盖。

## 仍未验证（同前）

- 真实 Let's Encrypt 签发与自动续期（腾讯云创建路径本轮已按文档修正，仍未用真实账号跑通
  完整签发）；
- 其他 DNS 提供商的真实账号联调；
- 真机 `docker compose` 长期运行、浏览器逐页 E2E、24 小时长跑与压测。

## 升级

换镜像即可，配置与数据兼容：

- 重启后需要重新登录一次（会话在内存里）；
- 如果此前用脚本以 `{username, password}` 调用登录接口，需要改成只发 `password`；
- 浏览器强刷一次拿到新界面。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc6-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc6 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
