# nunt v1.0.0-rc31

第三十一个候选版本：概览页两张趋势图改用单调插值，服务卡片重做成磁贴栅格。

**没有配置变更**，升级后不需要重新配置任何规则。

## 趋势图：曲线不再骗人

bklit 的折线默认用 `curveNatural`（自然三次样条），它在两个小时桶之间会**过冲**：

- 峰值可以画得比真实数值更高；
- 拐点落在两个整点之间，看起来像发生在某个中间时刻；
- 零值附近甚至会出现负向的凹陷。

现在改用 **`curveMonotoneX`**（单调插值）：依然平滑，但**经过每一个数据点**且不会在两个点之间
凭空造值。曲线的尖峰高度就是那一小时的真实数值，拐点也落在整点桶上。

## 服务卡片重做

原来的四行「名称 + 数值 + 说明」读起来像表格脚注，现在改成 **2×2 磁贴**：

```
🌐 Web 服务        ⇄ 端口转发
14 条路由          3 个监听
2 个监听器          12 个活跃连接

🔗 动态域名        🛡 证书
2 个启用           3 张
3 条规则           1 张 30 天内到期
```

- 每个服务一个语义图标（地球 / 交换箭头 / 链接 / 证书盾牌），颜色沿用原来的四色；
- 数字 20px 成为视觉重心，单位与说明依次弱化，层级是「是什么 → 多少 → 补充」；
- 数字使用 `tabular-nums`，四块字宽一致，扫读时不跳动；
- 底色、描边、圆角全部取自 antd token，深浅色自动跟随；
- 四个磁贴等宽等高，和左侧「系统资源 / 磁盘」的块状节奏对齐。
