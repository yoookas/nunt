# nunt v1.0.0-rc12

第十二个候选版本：Web 与端口转发的列表重做并支持拖拽排序；IP 地址库改为上传，
并补上 IPv6 支持。

## Web 服务页

- 左栏监听器、右栏路由，两边用同一种列表语言：**标题 + 筛选 + 表格**，
  不再「卡片里套卡片」；
- 路由表改为 **primary 表格**（灰底容器 + 白色行卡片），列为
  站点 / 类型 / 上游 / 安全 / 请求 / 状态 / 操作：
  - 站点：域名 + 路径/规则名，全部监听器视图下带监听器标签；
  - 安全：`TLS 开/关` 与 `WAF 开/关` 两个标签；
  - 状态（启停开关 + 运行中/已停用）位于**倒数第二列**；
  - 操作收成一个下拉菜单：查看访问日志 / 编辑路由 / 删除路由；
- 路由表单的「高级选项」集中到表单**底部一个区块**，展开后优先级、备注、
  超时、限速、请求体上限、路径重写、自定义头与 CORS 都在同一处；
- 监听器行保留启停开关、编辑与删除。

## 拖拽排序

- Web 监听器、Web 路由、端口转发规则都支持拖动左侧握把排序，**松手即保存**；
- 键盘可用：聚焦握把 → 空格拿起 → 方向键移动 → 空格放下；
- 新建的监听器 / 路由 / 转发规则**排在列表最上面**；
- 过滤或搜索状态下拖动，只重排可见项，被隐藏的条目保持原位；
- 路由顺序参与匹配：路径长度与 `priority` 相同时，**靠前的优先**。

## 端口转发页

- 规则列表与 Web 路由统一：标题 + 筛选 + primary 表格，去掉外层面板；
- 列合并为 规则 / 限制 / 统计 / 状态 / 操作，行内两行信息：
  源 → 目标、访问控制与超时、并发上限、活跃/累计连接与上下行流量；
- 操作收成一个菜单，窄列里不再竖排。

## IP 地址库

- 改为**上传 xdb** 并立即启用，移除了手动填路径的输入框；
- 上传前校验文件头与版本，**校验失败返回 400，不会替换正在使用的库**；
- IPv4 与 IPv6 **各一份库**，分别上传、互不影响；
- IPv6 地址现在真正参与国家/省份过滤。此前 v6 库虽然能被加载，但查询路径对
  非 IPv4 地址直接返回空，IPv4 查询还会拿 4 字节 key 去查 v6 的树；
- 省份下拉使用 v4 库（v6 库文件大，上传时不做全量省份扫描），
  没有 v4 库时回退内置列表；
- 「查询测试」同时支持 v4 / v6 地址。

## 修复

- 路由表单高级选项散落：优先级/备注在顶部，其余选项在「负载均衡」下方；
- 安全列只显示「关闭 / WAF 关」，含义不清；
- 路由表列宽不足导致的域名、监听器标签截断，「请求」表头被挤成两行；
- 端口转发操作按钮在窄列里竖排。

## 兼容性

- 配置新增可选字段 `system.ip2regionV6Db`；
- 原有的 `system.ip2regionDb` 继续生效，升级后可在「IP 地址库」页重新上传；
- 无需迁移；重启后需要重新登录，浏览器强刷一次。

## 验证

- 新增排序接口的参数校验测试（缺 id / 重复 / 未知 id 均拒绝）；
- ip2region 新增 IPv6 库查询测试与错误版本装载测试；
- 前端构建、11 条路由冒烟、`go vet`、api / config / ip2region 测试通过。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc12-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc12 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
