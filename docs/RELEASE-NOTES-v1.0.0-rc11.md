# nunt v1.0.0-rc11

第十一个候选版本：界面去掉多余的层套层，并把监听器启停开关放到真正能看见的位置。
没有后端行为变化。

## 界面：减少嵌套、腾出空间

- **监听器侧栏**从「卡片里再放卡片」改成**扁平列表**：每行一个监听器，
  第一行是名称 + TLS 标签（+ 已停用），第二行是地址、路由数、mTLS；
  编辑与删除收成右侧两个图标按钮，行之间用分隔线；
- **监听器与路由两个面板改为 flush**，内容从面板边缘开始，去掉了双层留白；
- **表格默认改为扁平样式**（HeroUI Table 的 secondary 变体）：之前每个表格都在
  面板里再画一层「灰底 + 白卡片」，现在表格直接铺在面板上；需要卡片样式的页面
  可以显式传 `variant="primary"`；
- 左栏宽度 340 → 320，两栏间距相应收紧。

## 修复：监听器启停开关看不见

上一个版本把开关放进了监听器表格的列定义，但侧栏改成列表后那段代码已不再渲染。
现在开关就在**每个监听器行的右侧**（编辑/删除图标左边），关 = 停用、开 = 启用；
端口仍被占用时开关保持关闭并提示。

同时把路由表的「状态」开关从最右侧（会被横向滚动挤出屏幕）移到「路径」之后。

## CI

- Docker smoke 修好了两处陈旧假设：登录请求不再带 `username`；全新容器首次登录
  必须先改密，冒烟会先走这一步再验证模块列表。现在 CI 与 Docker smoke 都是绿的。

## 升级

换镜像即可；重启后需要重新登录，浏览器强刷一次。

## 验证建议

打开 Web 服务页，确认：左栏是紧凑的列表、每行右侧有启停开关；路由表里「状态」
开关在「路径」后面可见；表格与面板之间不再有嵌套的白卡片。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc11-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc11 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
