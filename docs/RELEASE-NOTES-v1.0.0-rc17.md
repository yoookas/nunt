# nunt v1.0.0-rc17

第十七个候选版本：修掉表格在窄容器里被裁切、列被压成竖排的问题，并把 Web 路由的
访问日志弹窗压进一屏。

## 表格：宽表不再被裁

HeroUI 的表格根节点是 `overflow-clip`，表格一超宽就被裁掉，而不是出现滚动条；
此前 DataTable 在桌面端又设了 `min-w-0`，于是列被挤压（客户端 IP 会一个数字一行）。

现在改为：

- 表格按内容宽度展开（`min-w-max`），宽了就横向滚动，不再裁切或压字；
- 表头不再换行，避免「客/户/端」竖排；
- 只要有溢出就显示左右滚动按钮，不再只在手机宽度显示；
- 需要精确贴合的表格仍可单独覆盖（Web 路由表继续使用固定布局）。

## 路由访问日志弹窗

- 弹窗加宽（`wide`，最大 1152px）；
- 列从 9 列合并为 5 列，两行单元格：
  - 时间 / 客户端；
  - 请求：方法 + 路径，第二行 User-Agent；
  - 结果：状态 + 耗时，第二行大小；
  - 上游；
- 实测弹窗内容正好放下（`scrollWidth == clientWidth`），不需要横向滚动；
- 路径、UA、上游过长时截断，悬停可看全文。

## 其他

- 删除路由失败时不再一律返回 404「rule not found」，而是返回真实的校验错误。

## 验证

- Playwright 实测 1280px 窗口下弹窗：内容宽 1104 / 容器 1104，五列完整；
- 前端构建、11 条路由冒烟、web 包测试、全量 `go vet` / `go test ./...` 通过。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc17-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc17 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
