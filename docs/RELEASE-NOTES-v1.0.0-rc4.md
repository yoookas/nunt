# nunt v1.0.0-rc4

第四个候选版本：修 rc3 暴露的问题，并把「账户」收敛成一个密码。

## 修复

- **腾讯云 DNS 首次签发/续期失败**：`DescribeRecordList` 对还没有任何记录的子域名返回
  `ResourceNotFound.NoDataOfRecord`（HTTP 200 + Error 字段），旧代码把它当成调用失败，
  于是 dns-01 永远建不了第一条 TXT 记录，续期一直报「记录列表为空」。现在按空列表处理，
  调用方会创建记录。
- **日志里的错误显示成 `error={}`**：`error` 值直接进 JSON 会变成空对象。日志层现在统一把
  error 转成消息文本、时间转 RFC3339、耗时带单位；ACME 的失败日志同时补上域名、挑战方式、
  提供商与耗时。

## 破坏性变更

- **不再有用户名**。管理后台只有一个密码：
  - 登录页只填密码；旧的 `{username, password}` 登录体（例如脚本里）现在返回 400；
  - `/api/v1/auth/users`（用户列表/增删改）与 `/api/v1/auth/mode` 已移除；
  - 会话、审计日志、TOTP 日志都不再带名字；验证器里的标签是固定的 `nunt`；
  - 设置页删掉了「用户」标签、按用户重置密码，会话表不再有用户列；
  - 老配置里若还有多个账号，加载时只保留第一个，其余丢弃；`username`、`role`、`enabled`
    字段被忽略并在下次写配置时消失。

## 新增与改进

- **登录页也能切换颜色模式**（浅色 / 深色 / 跟随系统），和后台顶栏共用同一个组件；
- **运行日志可点击**：每行弹出结构化详情（时间、级别、组件、消息 + 字段表），支持复制 JSON；
- 登录失败现在按 **来源 IP** 计数（原来是「用户名 + IP」）；
- DNS 服务商显示名简化为「腾讯云」。

## 仍未验证（与前几个 RC 相同）

- 真实的 Let's Encrypt 签发与自动续期（腾讯云的记录创建路径本轮修好了，但仍未用真实账号跑通完整签发）；
- 其他 DNS 提供商的真实账号联调；
- 真机 `docker compose` 的长期运行；
- 浏览器逐页 E2E（只有 jsdom 挂载冒烟）；
- 24 小时长跑与压测。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc4-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc4 docker compose up -d
```

`amd64` / `arm64` / `armv7` 为单架构归档，`-oci.tar.gz` 是三平台合一的 OCI 布局（需 `ctr` 或 podman）。
四个归档的校验和都在 `SHA256SUMS` 里。

## 从 rc3 升级

换镜像即可。升级后需要**用密码重新登录一次**（会话本来就存在内存里，重启即失效）。
如果此前用脚本以 `{username, password}` 调用登录接口，需要改成只发 `password`。
