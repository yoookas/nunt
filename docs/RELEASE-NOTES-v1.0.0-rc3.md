# nunt v1.0.0-rc3

第三个候选版本。这一轮的主线是**收窄对外暴露面**和**把错误及时暴露出来**，没有引入新的配置字段。

## 移除

- **API Token 与开放 API 鉴权**：现在只剩浏览器会话一种鉴权方式。设置页的 Token 标签、`/auth/tokens` 接口、
  `Authorization: Bearer` / `X-API-Token` 通道、scope 检查全部移除。旧配置里的 `tokens` 字段会被忽略，
  下次写配置时自然消失。
- **`/metrics`**：没有 Token 之后抓取器无法通过鉴权，端点一并移除。同样的数值在概览页和日志里都能看到。

> 如果有人用 Token 调 API 或让 Prometheus 抓 `/metrics`，升级前请确认不再需要——这两条会中断。

## 界面

- **颜色模式增加「跟随系统」**：浅色 / 深色 / 跟随系统三选一，默认跟随系统，系统切换时实时同步；
  首屏不再强制深色（浅色系统不会再闪一下深色）。
- **手机布局修复**：统计卡片不再竖排居中、长提示不再被裁到卡片外；卡片标题栏在窄屏改为纵向堆叠、左对齐。
- **证书页**：证书仓库改为第一个 Tab。
- 列表筛选并入卡片标题行（Web 路由 / DDNS / 转发）；没有监听器时不再显示「全部监听器 0」。
- 控件尽量换回 HeroUI 原生组件（`SearchField`、`Avatar`、`Tag.RemoveButton`、`Button`），手写控件减少；
  顶栏不再改写官方 `Header` 组件的样式。

## 可观测

- **日志全部中文**，并补齐细节：启动/关闭耗时、每个模块的启动耗时、DDNS 每次执行（此前一条日志都没有）、
  登录失败的具体原因、审计记录的 method/path、HTTP 请求的 host 与客户端地址、备份归档大小。
- 运行日志页新增「组件」列，关键字过滤也会匹配组件名。
- 顶栏新增**全局问题指示**：证书到期、证书续期失败、模块未启动，任何页面都能看到，点开可跳到概览；
  证书页的「上次任务失败」改为 toast（同一错误只提示一次），不再常驻横幅。

## 升级注意

- 从 rc2 升级：换镜像即可，配置字段没有变化；
- 若曾用 API Token 对接脚本或监控，本版本会中断，请先迁移（目前没有替代的非会话鉴权）。

## 仍未验证（与前两个 RC 相同）

- 真实的 Let's Encrypt 签发与自动续期；
- DNS 提供商真实账号联调（腾讯云上一轮修了签名，但仍是假 API 验证）；
- 真机 `docker compose` 的长期运行；
- 浏览器逐页 E2E（只有 jsdom 挂载冒烟）；
- 24 小时长跑与压测。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc3-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc3 docker compose up -d
```

`amd64` / `arm64` / `armv7` 为单架构归档，`-oci.tar.gz` 是三平台合一的 OCI 布局（需 `ctr` 或 podman）。
四个归档的校验和都在 `SHA256SUMS` 里。
