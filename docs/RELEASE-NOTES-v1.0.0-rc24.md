# nunt v1.0.0-rc24

第二十四个候选版本：一次完整安全复核后的修复批次，加上 CI 与测试基建的改进。
**没有新增功能，没有配置格式变化，没有 API 变更——替换镜像即可。**

## 安全修复

- **管理端会话 Cookie 的 `Secure` 标志真正生效**。管理端监听器自己不做 TLS，原先
  `r.TLS != nil` 的判断在正式部署里恒为假，这个标志从未置位过。现在它与客户端 IP 共用同一套
  可信代理策略：直连 TLS，或直连对端是可信代理且声明 `X-Forwarded-Proto: https` 时置位。
  纯局域网 HTTP 部署保持不带——明文连接上设置的 Secure Cookie 会被浏览器直接丢弃，
  强行加会让「登录看起来成功、下一个请求就掉线」。
- **HSTS 不再相信任意客户端**。`X-Forwarded-Proto` 只从可信代理读取，客户端无法让服务
  为一条从未加密的连接承诺 TLS。
- **上游无法伪造后台 Cookie**。反向代理在响应方向也会剥离 `nunt_session`，与请求方向对称。
  Cookie 按主机名而非端口隔离，同主机名（或经 `Domain=` 的兄弟子域）上的站点此前可以覆盖
  管理员会话，把操作者踢下线。
- **管理端请求体读取有上限**。`ReadTimeout` 从 0 改为 60 秒：登录接口不需要会话，
  此前可以被慢速请求体长期占用连接（限流器限制的是发起速率，不是占用时长）。
  ip2region 地址库上传单独放宽到 30 分钟，慢链路上仍可完成。
- **证书存储拒绝逃逸名**。上传证书的 SAN 为 `..` 一类值时，派生出的目录名会成为路径表达式，
  此前只能靠内核拒绝 `rename` 兜底。现在只保留单一路径元素允许的字符，落盘前再用 `validID`
  校验，报错直接指出是哪个域名；合法域名的目录名与以前完全一致。
- **访问日志导出中和公式注入**。Host、路径、User-Agent、WAF 消息都由请求方控制，以
  `= + - @` 开头的单元格会被加上 `'` 前缀，用 Excel 打开导出文件不再有公式执行风险。
- **只读管理接口补齐权限校验**。会话列表与备份列表/配置现在也走 `requireAdmin`
  （当前每个会话都是管理员，行为不变，只是把唯一开关留给未来的只读角色）。

## CI 与测试

- **依赖漏洞扫描每周定时重跑**。`govulncheck` 本来就是阻塞 job，但只在 push / PR 时运行，
  提交之后才公布的 CVE 要等到下次提交才会被发现；现在每周一 03:00 UTC 单独跑一次，
  只运行扫描，不重建前端与镜像。
- **测试快了约 9 倍**。测试配置改用便宜的 Argon2id 参数集——参数存在 PHC 字符串里，
  验证路径与生产完全一致，只是成本更低。`internal/api` 在 `-race` 下从 638 秒降到 70 秒，
  全量 `-race` 约 6 分 45 秒；CI 因此撤回了此前为它加的 `-timeout 20m`，
  默认十分钟重新变成有意义的信号。
- 新增 `internal/testutil`（仅测试引用，不进二进制），并提供 `Add`、`IDFor`、CSV 导出、
  可信代理策略、HSTS 下发、管理端超时等回归测试。

## 兼容性

- 无配置格式变化、无 API 变更、无数据库迁移；替换镜像即可；
- **部署注意**：管理后台如果放在 TLS 终结代理后面，需要在「设置 → 信任反向代理」里把代理
  地址填进 `system.trustedProxies`（并开启 `system.trustProxy`），否则后台 Cookie 不会带
  `Secure`、Web 监听器的 HSTS 也不会下发。纯局域网 HTTP 访问不需要任何改动。
- 上游站点无法再设置名为 `nunt_session` 的 Cookie（该名称由管理端保留）。

## 验证

- `gofmt` 无未格式化文件；`go vet ./...` 通过；`go build ./...` 通过；
- `go test ./... -count=1`：22 个包全部通过；
- `go test -race ./... -count=1`：22 个包全部通过；
- 前端本次没有改动，未重跑 `npm run build` 与 `smoke`；
- 镜像与四个归档由 release workflow 在打 tag 后构建，本机未构建镜像。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc24-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc24 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
