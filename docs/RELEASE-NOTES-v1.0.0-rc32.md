# nunt v1.0.0-rc32

第三十二个候选版本：端口转发页的访问规则标签显示错误，列表项与 Web 服务页对齐。

**没有配置变更**，升级后不需要重新配置任何规则。

## 修复：访问规则标签永远显示「关闭」

转发规则的访问标签还在读**旧模型**（`allow` / `deny` + `ips[]`）：现在的访问控制是
`off / rules / inherit` 加有序列表，`mode: "rules"` 落不进旧分支，被归成 `off`，于是：

- 不管有没有配规则，标签永远是「关闭」；
- 条数永远读 `ips`（字段已不存在），永远是 0。

现在改用 Web 页共用的 `AccessTag`：显示「规则 N 条 · 其余拦截」，颜色按「其余」动作区分；
**没配访问规则时整个标签不显示**，不再用「关闭」占位。

## 端口转发列表与 Web 服务页对齐

列表项现在是同一套结构：

```
● 名称                            [开关]     第一行：标题 + 启停
  :57314 → 10.0.0.2:44222                     第二行：监听 → 目标
  [TCP] [规则 1 条 · 其余拦截] 活跃 1 · ↑ 0 B   第三行：标签 + 计数
```

- 启停开关直接放在列表行上，不用先点进详情；
- 未启用的规则补「已停用」标签，状态点变灰；端口被占用仍显示红色「端口占用」；
- 详情页头部的「监听中」标签删除——列表的绿点已经表示状态；
- 详情页头部的开关也删除：同一个 `enable` 有两个开关，而且详情那个读的是
  `enable && !disabled`，端口被占用的规则会被显示成关闭、点了也不会重新绑定。
  「端口被占用」提示相应改指向列表开关。
