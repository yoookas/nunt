# nunt v1.0.0-rc14

第十四个候选版本：窄窗口下的 Web 路由表不再被裁掉；端口转发规则在端口被占用时
自动停用，打开开关前也会真正尝试绑定。

## Web 路由表：窄窗口适配

- 路由行从 7 列合并为 5 列：**站点 / 路由（类型 + 上游）/ 安全 / 状态 / 操作**，
  请求数移到状态列第二行；
- 表格改为固定布局，长域名、长上游一律截断，不再把表格撑出容器（此前 HeroUI
  表格根节点会直接裁掉超出部分）；
- 表格设置最小宽度：宽窗口完整显示不滚动；窗口较窄时列不会被压扁，改为横向滚动，
  并在下方显示「表格超出屏幕，可左右滚动查看」和左右按钮（原来只在手机显示）；
- 1163px 窗口实测 `scrollWidth == clientWidth`，五列完整可见。

## 端口转发：端口占用检测

- 规则启动（含模块启动、配置重载、新建、编辑保存）时真实尝试绑定，失败则
  **自动停用**并写入配置，不再每次重载反复重试；
- 列表里开关自动关闭，状态列显示「端口被占用」，统计里的「启用」不再计入它；
- 打开开关时立即尝试绑定：端口仍被占用返回 **409** 并保持停用，释放后再开会正常启动；
- 配置新增可选字段 `forward.rules[].disabled`，旧配置无需迁移。

## 验证

- 新增 `TestReloadAutoDisablesBusyPort`：占用端口 → 自动停用；释放后重新装载 → 正常监听；
- 实机验证：占用 18096 创建规则自动停用、占用中开开关 409、释放后开开关 200 且
  `listening: true`、关闭开关 200；
- `go vet`、全量 `go test ./...`、前端构建与 11 条路由冒烟通过。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc14-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc14 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
