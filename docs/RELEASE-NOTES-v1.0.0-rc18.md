# nunt v1.0.0-rc18

第十八个候选版本：访问日志迁到 SQLite 并记录请求级细节，长表格改为虚拟滚动，
运行日志改成最新在上、顶部跟随。

## 访问日志：SQLite 与更详细的记录

- 访问日志从「按天 JSONL」改为单个 SQLite 文件
  `<数据目录>/logs/access/access.db`（纯 Go 驱动，交叉编译不受影响）；
- 写入仍走有界队列 + 单写协程，改为批量事务；保留按天清理，超过数据库上限时删除最旧记录；
- 查询改为索引 SQL，去掉了原来的 30 万行扫描上限，过滤、游标分页、统计和趋势图共用同一套条件；
- 每条记录新增：请求 ID、拒绝原因或代理错误、上游状态与重试次数、请求/响应字节拆分、
  HTTP 协议与 TLS 版本；请求 ID 同时写入响应头 `X-Request-ID`，并出现在 WAF 与转发记录里；
- 日志页状态下方直接显示拒绝原因/错误，新增请求 ID 列；CSV 导出扩充到 24 列；
- **旧 JSONL 不迁移、不导入、不删除**，确认无用后可手动清理。

## 表格：虚拟滚动与固定高度

- `DataTable` 新增可选的虚拟滚动：固定高度视口、表头吸顶、只渲染可见行；
- 访问日志表已启用：行高 64px，滚动接近底部自动加载下一页（每页 100 条），筛选变化回到顶部；
- 桌面和手机仍是同一张表；表头不换行，手机横向滑动带惯性与边缘渐隐提示；
- 不再使用手机专用的卡片列表，也不再固定首列。

## 运行日志

- 顺序改为**最新在最上方**；
- 停在顶部时自动跟随：新事件插入顶部、视图不跳；向下滚动暂停，滚回顶部恢复；
- 「自动滚动」开关移到表格上方的面板头部，与访问日志的「自动刷新」同一位置。

## 前端清理

- 删除无调用者的组件、状态、属性和导入；
- `tsconfig` 启用 `noUnusedLocals` / `noUnusedParameters`，后续构建会直接拦截未使用代码。

## 升级说明

- 访问日志数据库是新增文件，旧 JSONL 保持原样；备份仍只包含配置、密钥与证书，不含日志；
- 数据目录不要放在 NFS 上（SQLite 需要本地文件系统）；
- 默认保留 7 天、数据库上限 64 MB，可在「设置 → 日志」调整到 4096 MB。

## 验证

- 703 条访问记录时，表格 DOM 仅保留约 20–29 行，滚动自动加载 100 → 200 → 500；
- 手机视口下同一张表可横向滑动，表头吸顶；
- 运行日志 95 条时最新在上；滚到 400px 后新事件不抢滚动，回到顶部后恢复跟随；
- 全量 `go vet` / `go test ./...`、前端构建与 11 条路由冒烟通过。

## 镜像与校验

```sh
docker load < nunt-v1.0.0-rc18-amd64.tar.gz
NUNT_IMAGE=nunt:v1.0.0-rc18 docker compose up -d
```

四个归档（amd64 / arm64 / armv7 / oci）的校验和都在 `SHA256SUMS` 里。
